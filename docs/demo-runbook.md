# Demo 运行手册（Spec §19 十七步 → 实际操作）

> 2026-07-31 编制。每步标注【就绪】【替代演示】或【口头说明】——
> 不假装演示没有实现的东西。录屏前把本手册过一遍即是彩排清单。

## 起手

```bash
make api          # 127.0.0.1:8000
make web          # 127.0.0.1:3100
# Moodle（可选，步骤 2 的真实链路）：
gcloud compute ssh campuspath-moodle --zone=asia-east2-a -- -L 8080:localhost:8080
```

打开 `http://localhost:3100` → 自动跳到 `/login`。**先演示两个门户各自登录**：
学生卡选 STU-A（口令 = 环境变量 CAMPUSPATH_DEMO_PASSCODE 的值，团队口头分发）；另开窗口用校方卡登录 curator——两边导航互不可见，
跨门户 URL 会被弹回。这本身就是 D5 的第一幕。

延迟实测（2026-07-31）：`/matches` 热路径 P50 ≈ 2.3s（阈值 <3s）；
冷启动首调约 22s（Vertex 初始化 + 理由生成），**演示前先热身调一次**。
